# Prayer Book Hymnal

## Purpose
The Prayer Book Hymnal is a supplement to the 2025 Proposed Book of Common Prayer. The Office propers for all of the Feast Days have been provided, the Hymns set to Gregorian notation. Devotional hymns as well are provided.

## Languages
LuaLaTeX is used for the Prayer Book Hymnal, except for the Devotional Hymns. The Devotional Hymns are made using MuseScore, then the PDF is inserted via LaTeX.

## Textual Bases
For the Office propers, the Monastic Breviary is used, with Solesmes being used for the notation. For the Mass propers, the English Missal is used. Exceptions for certain Feast Days noted in the comments.

## Status
The Prayer Book Hymnal is almost completed. We decided to omit the Mass propers, since those are provided in the Missal. Instead, we are focusing on the Office propers and the Devotional Hymns.
